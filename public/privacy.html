Política de Privacidade

A sua privacidade é uma prioridade. Aqui explicamos com total transparência como o News AI Bot lida com as informações.

1. Dados Coletados

  • Identificadores de Usuário: Coletamos o seu Discord User ID apenas para associar o seu histórico de buscas às pontuações de sentimento no comando de gráfico.
  • Conteúdo de Mensagens: Processamos apenas as palavras-chave enviadas após os comandos (ex: o tópico da notícia). Não lemos mensagens privadas ou outros canais.

2. Uso das APIs de Terceiros

Para funcionar, o bot envia o tópico da busca para a GNews API e os textos das notícias para a Groq API (Llama 3.3). Nenhum dado pessoal identificável é enviado para essas APIs.

3. Armazenamento

Os dados de sentimento são armazenados localmente no servidor do bot para gerar os gráficos de tendência. Esses dados não são vendidos ou compartilhados com terceiros.

4. Exclusão de Dados

Como não possuímos um sistema de contas permanente, seus dados de histórico podem ser limpos periodicamente conforme a manutenção do servidor.
